🔖 FaastU Icons

שפת אייקונים אחת, שמשרתת כמה פרויקטים. ציור אחד = מזהה אחד, קבוע לנצח.

דף הקונטקט — לראות את כל האייקונים ←

שתי הכתובות שצרכן צריך

  • build/icons.json — המניפסט: מי כל אייקון, מה הוא אומר, ולאילו תגיות הוא קשור.
  • build/sprite.svg — כל הציורים בקובץ אחד.

איך משבצים באתר

⚠️ אי אפשר להצביע על ה-sprite מדומיין אחר. הדפדפן חוסם <use> בין מקורות. צריך למשוך את הקובץ ולהזריק אותו לדף — פעם אחת, בראש ה-<body>. 
const BASE = "https://shefyg.github.io/faastu-icons/build/";

fetch(BASE + "sprite.svg")
  .then(r => r.text())
  .then(t => document.body.insertAdjacentHTML("afterbegin", t));

// ואז, לכל אייקון:
// <svg class="icon" aria-label="Video" role="img"><use href="#icon-video"></use></svg>
//
// הצבע נשלט ב-CSS:  .icon { width:20px; height:20px; color:#5a6472; }

מזהה שלא קיים

הספרייה מחזירה #icon-missing — ריבוע קו ריק. העמוד לא נשבר ולא נפער בו חור.

להוסיף אייקון

  1. קובץ SVG ל-icons/ — קו בלבד, currentColor, בלי <title> ובלי id.
  2. שורה מלאה ל-icons.json.
  3. node tools/build.js — הוא עוצר אם משהו חסר.
  4. השער: שפי מאשר בעין · שורת מניפסט מלאה · נוגה בודקת ניגודיות ו-375px.
